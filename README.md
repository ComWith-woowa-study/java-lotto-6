## 기능 목록

### 입력
- [x] 로또 구입 금액을 입력 받는다.
  - [x] 양의 정수 이외의 값을 입력할 경우 예외 처리한다.
  - [x] 구입 금액이 비어있으면 예외 처리한다.
- [x] 당첨 번호를 입력받는다.
  - [x] 쉼표를 기준으로 구분한다.
  - [x] 양의 정수 이외의 값을 입력할 경우 예외 처리한다.
  - [x] 당첨 번호가 비어있으면 예외 처리한다.
  - [x] 중복값을 입력할 경우 예외 처리한다.
- [x] 보너스 번호를 입력 받는다.
  - [x] 양의 정수 이외의 값을 입력할 경우 예외 처리한다.
  - [x] 보너스 번호가 비어있으면 예외 처리한다.
  - [x] 당첨 번호와 중복된 번호를 입력할 시 예외 처리한다.

### 출력
- [x] 발행한 로또 수량 및 번호를 출력한다.
  - [x] 로또 번호는 오름차순으로 정렬하여 보여준다.
- [x] 당첨 내역을 출력한다.
- [x] 수익률은 소수점 둘째 자리에서 반올림한다.
- [x] 예외 상황 시 에러 문구를 출력해야 한다.
  - [x] 에러 문구는 `[ERROR]`로 시작해야한다.

### 기능
- [ ] 로또 번호의 숫자 범위는 1~45까지이다.
  - [ ] 로또 번호의 숫자 범위 이외의 입력이 오면 예외 처리한다.
- [ ] 로또 1장의 가격은 1,000원이다.
- [ ] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
  - [ ] 로또 1장 가격으로 나누어 떨어지지 않는 경우 예외 처리한다.
  - [ ] 개당 로또 번호의 숫자 범위에 맞는 6개의 랜덤 숫자를 뽑는다.
- [ ] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 알려주고 로또 게임을 종료한다.
